# Implementasi Geographic Information System untuk Pemetaan Fasilitas Publik dan Jaringan Jalan di Kota Bengkulu

## Ringkasan

Proyek ini menggunakan data geospasial OpenStreetMap untuk memetakan fasilitas publik dan jaringan jalan di Kota Bengkulu. Data tersebut diolah untuk melihat persebaran objek serta menampilkan informasi lokasi dalam bentuk peta.

## Dataset

- **Nama:** OpenStreetMap (OSM)
- **Sumber resmi:** https://www.openstreetmap.org/
- **Informasi hak cipta dan atribusi:** https://www.openstreetmap.org/copyright
- **Wilayah analisis:** Kota Bengkulu
- **Jenis data:** Koordinat geografis, fasilitas atau amenity, dan jaringan jalan.

Notebook mengambil data spasial dari OpenStreetMap melalui koneksi internet menggunakan Python.

## Tujuan

1. Mengambil data geospasial untuk wilayah Kota Bengkulu.
2. Mengidentifikasi fasilitas publik berdasarkan kategori.
3. Menganalisis jumlah dan persebaran objek yang ditemukan.
4. Memvisualisasikan fasilitas pada peta.
5. Mengambil dan menampilkan jaringan jalan.
6. Menunjukkan penerapan pengolahan data spasial dalam mendukung analisis wilayah.

## Metode dan keluaran

- Pengambilan data geospasial dari OpenStreetMap.
- Penentuan wilayah kajian dan koordinat.
- Pengelompokan objek berdasarkan kategori fasilitas.
- Penghitungan jumlah objek per kategori.
- Visualisasi titik fasilitas pada peta.
- Pengambilan dan visualisasi jaringan jalan.
- Tabel ringkasan kategori dan jumlah objek.

## Batasan dan penggunaan yang bertanggung jawab

- Kelengkapan dan ketelitian data OpenStreetMap dapat berbeda antarwilayah.
- Jumlah fasilitas yang ditemukan bukan berarti jumlah resmi seluruh fasilitas di Kota Bengkulu.
- Data dapat berubah karena diperbarui oleh kontributor OpenStreetMap.
- Pengambilan data memerlukan koneksi internet dan harus mengikuti ketentuan layanan sumber data.
- Atribusi OpenStreetMap wajib dicantumkan ketika menggunakan atau menampilkan datanya.
