# Implementasi Geographic Information System untuk Pemetaan Fasilitas Kesehatan dan Jaringan Jalan di Kecamatan Ratu Agung, Kota Bengkulu

## Ringkasan

Proyek ini menggunakan data geospasial OpenStreetMap untuk memetakan fasilitas kesehatan dan jaringan jalan di Kecamatan Ratu Agung, Kota Bengkulu. Data tersebut diolah untuk melihat persebaran objek serta menampilkan informasi lokasi dalam bentuk peta.

## Dataset

- **Nama:** OpenStreetMap (OSM)
- **Sumber resmi:** https://www.openstreetmap.org/
- **Informasi hak cipta dan atribusi:** https://www.openstreetmap.org/copyright
- **Wilayah analisis:** Kecamatan Ratu Agung, Kota Bengkulu
- **Jenis data:** Koordinat geografis, fasilitas kesehatan (amenity), dan jaringan jalan.

Notebook mengambil data spasial dari OpenStreetMap melalui koneksi internet menggunakan Python.

## Tujuan

1. Mengambil data geospasial untuk wilayah Kecamatan Ratu Agung, Kota Bengkulu.
2. Mengidentifikasi fasilitas kesehatan berdasarkan kategori.
3. Menganalisis jumlah dan persebaran objek yang ditemukan.
4. Memvisualisasikan fasilitas kesehatan pada peta.
5. Mengambil dan menampilkan jaringan jalan.
6. Menunjukkan penerapan pengolahan data spasial dalam mendukung analisis wilayah.

## Metode dan keluaran

- Pengambilan data geospasial dari OpenStreetMap.
- Penentuan wilayah kajian dan koordinat pusat.
- Pengelompokan objek berdasarkan kategori fasilitas kesehatan.
- Penghitungan jumlah objek per kategori.
- Visualisasi titik fasilitas kesehatan pada peta.
- Pengambilan dan visualisasi jaringan jalan.
- Tabel ringkasan kategori dan jumlah objek.

## Batasan dan penggunaan yang bertanggung jawab

- Kelengkapan dan ketelitian data OpenStreetMap dapat berbeda antarwilayah.
- Jumlah fasilitas yang ditemukan bukan berarti jumlah resmi seluruh fasilitas di Kecamatan Ratu Agung, Kota Bengkulu.
- Data dapat berubah karena diperbarui oleh kontributor OpenStreetMap.
- Pengambilan data memerlukan koneksi internet dan harus mengikuti ketentuan layanan sumber data.
- Atribusi OpenStreetMap wajib dicantumkan ketika menggunakan atau menampilkan datanya.
